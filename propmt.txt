Build a full frontend web application for QAB (Query-driven Agent Builder) — a SaaS platform where users create AI agents powered by RAG (Retrieval-Augmented Generation). Users can link databases, upload documents to a Knowledge Base, and chat with agents.

🎨 Design Direction
Design Direction
Clean, crisp white and blue theme — professional SaaS feel. Use a pure white (#FFFFFF) base with a primary blue palette (e.g. #2563EB / #1D4ED8) for actions, highlights, and accents. Sidebar in a soft off-white or light gray (#F8FAFC). Text in deep slate (#0F172A) for contrast. Blue gradient accents on hero elements like the dashboard header or agent cards. Subtle blue-tinted shadows and borders (#DBEAFE, #BFDBFE). Inspired by tools like Notion, Linear (light mode), or Stripe Dashboard — clean, spacious, trustworthy, and modern.
Font pairing: A geometric sans-serif like DM Sans or Plus Jakarta Sans for UI, with Inter for body/data text. Avoid dark backgrounds entirely — this is a full light-mode product.

📄 Pages & Features to Build
1. Auth Pages

/register — Name, Email, Mobile, Password fields
/login — Email, Password fields
Store JWT access token in memory/localStorage on login

2. Dashboard (Home)

Overview cards: Total Agents, Knowledge Bases, Linked DBs
Quick action buttons: "Create Agent", "Create Knowledge Base"

3. Agents Page (/agents)

List all agents (cards with name, description, model, linked KB)
Create Agent form/modal: name, description, role, instruction, provider (Groq/Gemini), model, temperature slider, KB selector
Edit & Delete actions per agent

4. Knowledge Base Page (/knowledge-bases)

List all KBs (cards with name, linked DB, files count)
Create KB modal: name, DB selector (default or custom)
Per KB: upload .pdf or .txt files, view file list, delete individual files
Delete entire KB

5. Databases Page (/databases)

List linked DBs (MongoDB/Postgres) with name, provider badge
Link DB form: name, provider dropdown, connection URI
Unlink/delete button per DB

6. Chat Page (/chat/:agent_id)

Full-screen chat UI with message bubbles (user right, agent left)
Input box at bottom with Send button
Maintains thread_id for conversation continuity (generate UUID on session start)
Show agent name and model at top
Loading indicator while agent responds




🛠 Tech Stack

HTML / CSS / JS only.


✅ Additional Requirements

Protected routes: redirect to /login if no token
Toast notifications for success/error API responses
Responsive layout (sidebar nav on desktop, hamburger on mobile)
Sidebar nav links: Dashboard, Agents, Knowledge Bases, Databases, Logout
